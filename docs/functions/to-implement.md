# Backlog de módulos

Itens de planejamento identificados na documentação histórica:

- Tracker de candidaturas e Kanban.
- Currículo público com slug e métricas.
- Carta de apresentação e simulador de recrutador.
- Histórico de análises ATS e versões de currículo.
- Pipeline assíncrono de geração de PDF.
- API pública e versionamento externo.

Nenhum desses itens deve ser considerado parte da aplicação atual até existir código, migration e teste correspondentes.
