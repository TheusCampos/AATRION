# PRD histórico

> Este arquivo foi convertido em marcador para evitar que requisitos planejados sejam confundidos com funcionalidades entregues. A fonte atual de comportamento é o código e os documentos de `architecture/`, `api/`, `features/` e `flows/`.

O planejamento anterior incluía recursos como tracker de candidaturas, currículo público, cartas, simulador, filas de PDF e APIs adicionais. Eles não estão implementados no repositório atual.

Para planejar novos ciclos, use `docs/roadmap/` como histórico e crie uma proposta atualizada baseada no estado real documentado.
